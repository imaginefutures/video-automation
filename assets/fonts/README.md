# 인서트 글꼴 (docs/인서트-가이드.md 5장)

| 파일 | 글꼴 | 쓰는 곳 | 라이선스 |
|---|---|---|---|
| `gangwonedupowerextrabolda-normal.woff` | 강원교육튼튼체 (강원도교육청, 헤움디자인) | 얼굴 위 자막 | 무료 사용, 유료 양도·판매 금지 |
| `jeju-myeongjo-400.ttf` | 제주명조 (제주특별자치도, 산돌) | 어둡게 깔고 읽어 주는 인용 | 무료 배포 서체 |
| `Pretendard-ExtraBold.otf`, `Pretendard-Bold.otf` | 프리텐다드 1.3.9 (Kil Hyung-jin) | 삽화 노란 글씨, 모션그래픽 | SIL OFL 1.1 (`Pretendard-LICENSE.txt`) |

이 프로젝트에서 쓰기 위해 넣었다. 글꼴 자체를 판매하거나 유료로 넘기지 않는다 (10-09 사용자 결정).
파일이 없으면 `scripts/fonts.py`가 공개 미러에서 같은 버전을 받아 파일 지문을 확인한 뒤 `~/.video-cut/fonts/`에 둔다.
