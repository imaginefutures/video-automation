## 품질 루프 (`기획/`) — 백엔드 구현·검증 완료, 검토 화면(P4)도 완료. 이음새 대안 선택만 미배선

이음새 단위 부분 검증 + PD/시청자 관점 전체 평가, 최대 삭제 방침. **09-30 하향식 재설계**: 국소
탐지(`detect_ng_candidates.py`)+개별 분류(`classify_candidates.py`)+사후 전체 맥락 검토
(`whole_context_review.py`)의 상향식 3단 구조가 같은 문단 안 재시작 사슬조차 후보로 못 만드는
근본 문제를 실측으로 확인해 폐기하고, `detect_regions.py`(Stage 1, 전체를 넓게)→
`classify_region.py`(Stage 2, 부분을 좁게)의 하향식 2단 구조로 대체했다. `global_review.py`
(전체 루프)도 최대 2라운드 재투입 루프가 세션에 걸쳐 반복 실행되면 판단이 누적되는 문제를 겪어
정확히 1회로 단순화했다. `route_candidates.py`·`audio_map.py`(신규: 숨소리를 재시작 보강
신호로도 씀)·`assemble_draft.py`·`seam_refine.py`·`eval_against_gold.py`(신규: 순서 재배열
편집을 오판하지 않는 재검사)는 그대로 유지, `run.py`에 배선돼 이제부터 처리하는 모든 영상에 기본
적용. **검증 결과(사용자가 BS167 수동 편집 중 찾은 중복 탐지·경계 자기 불일치 버그 수정 후 최종):
BS145 정밀도 0.786·재현율 0.736(보정 0.781), BS167 정밀도 0.748·재현율 0.704(보정 0.764), 둘 다
오삭제 flag 누락 0건** — 목표(정밀도≥0.75·재현율≥0.7)를 BS145는 완전 달성, BS167도 정밀도가
목표와 사실상 동일한 수준까지 좁혀짐(상세 —
[`현재-설계/검증-결과-BS145.md`](현재-설계/검증-결과-BS145.md), [`현재-설계/검증-결과-BS167.md`](현재-설계/검증-결과-BS167.md)). 검토 화면(`server.py`/`web/`) 배선: 스냅 경계 반영, 전체 루프 over_cut/시청자 지적의 ng.json 역전파, `seam_refine.py` 자신의 이음새 판정(대안 실패·정보손실·G2 잔여음 의심)도 ng.json 역전파까지 완료. R1/R3로 확정 영수증 모달과 이음새 릴도 있음. (엔딩용 후보/outtake 표시 기능은 10-01에 제거됨.) **09-30 추가**: 확정 시 `learn_from_session.py`를 fire-and-forget으로 호출해 few-shot 학습 데이터가 자동으로 쌓이도록 연결(전에는 수동 실행이 필요했음). **10-01 완료**: 기획/05의 카드 전면 재설계(두 층 큐·PD/시청자 평가 배지·번호 키 1/2/3 대안)도 끝남(`721c860`) — 상세는 [`기획/05-검토-화면.md`](기획/05-검토-화면.md)·[`현재-설계/검토-화면.md`](현재-설계/검토-화면.md). 단, 이음새 루프 자체의 **대안 선택**(축소/확장 + LLM 문법·중복·정보손실 판정)은 아직 화면에 배선되지 않았다 — 화면은 지금도 NG 항목의 원래 플래그 범위를 그대로 쓴다(`SKILL.md` 참고).
