# R6. 한 번 검토로 더 많은 결과

상태: ⬜ 미착수 · 우선순위 3 (컷편집 안정 후) · 배경: [`왜-이탈하는가.md`](왜-이탈하는가.md)

확정 한 번으로 FCP에서 할 일이 줄어들수록 도구의 가치가 전체 편집 시간 대비 커진다. 전사·발화 경계·주제 전환 정보를 이미 갖고 있으므로 추가 검토 없이 뽑을 수 있는 것부터.

| 순서 | 산출물 | 재사용 자산 | 추가 비용 |
|---|---|---|---|
| 1 | 챕터 (`chapters.txt`, 유튜브 설명란 복붙) | 쉼 분류의 "주제 전환" 경계 | 거의 없음 |
| 2 | 엔딩 아웃테이크 코너 (별표 친 NG를 모은 FCP 컴파운드) | 아웃테이크 별표 (이미 있음) | 없음 |
| 3 | 자막 캡션 트랙 (4~7어절, 쉼·문장부호에서 끊기) | 단어 타임스탬프 | 없음 |
| 4 | 쇼츠 후보 (완결된 30~60초 구간 3개) | 발화 경계, 전체 맥락 LLM | 영상당 1회 호출 |
| 5 | ~~자료 화면 제안~~ → 별도 기획 [`자료-화면-삽입.md`](자료-화면-삽입.md)로 이동 (10-09) | — | — |
| 6 | 썸네일 후보 프레임 + 훅 문장 | 프레임 추출 | 선택 |

모두 "제안이 적용된 상태"까지만 만든다 ([`../서비스-개요와-철학.md`](../서비스-개요와-철학.md) 원칙 3). 자료 화면은 10-09부터 [`자료-화면-삽입.md`](자료-화면-삽입.md)에서 다룬다.

**메모: 3번(자막) 착수 시 검토할 것 — 워드바이워드 하이라이트 + 자동 이모지.** Submagic 벤치마크(경쟁 도구 조사, 2026-09-29)에서 확인: 말하는 순간의 단어만 강조되고(노래방 자막처럼), 문맥에 맞는 이모지가 자동 배치됨(수동 조정 없이 78% 정확도). 단어별 정확한 타임스탬프(Scribe)가 이미 있어서 구현 장벽 낮음 — 자막 청크 나누기(4~7어절)와 함께 스타일 결정 시 후보로 검토.

**결정 (2026-09-29): 하이라이트/쇼츠(4번)는 컷편집이 끝난 뒤 후속 기능으로 미룬다.**
- 이유: 지금 이 도구가 이겨야 할 대상은 "손으로 자르기"([`왜-이탈하는가.md`](왜-이탈하는가.md))다. 쇼츠 추출은 컷편집이 안정돼 "결과를 믿을 수 있다"가 먼저 성립해야 의미가 있다 — 본편 컷도 못 믿는데 거기서 하이라이트를 더 뽑는 건 순서가 바뀐 것
- 착수 조건: 위 표의 우선순위대로 챕터(1) → 아웃테이크(2) → 자막(3)까지 나온 뒤. "검토 시간이 안정된 뒤"와 동일한 판단
- 지금 하지 않는 것: 별도 하이라이트/훅 탐지 LLM 패스, 세로 크롭, 쇼츠용 캡션 번인 — 전부 착수 시점에 함께 설계
- 바뀌는 조건: 컷편집 자체(NG·쉼·화자블록) 검토 건수가 3편 이상 안정적으로 낮게 나오고, 자막까지 나온 뒤 재검토
