# 공통 자산 — 모든 영상이 같이 쓰는 파일을 한곳에

상태: ✅ A1·A2 구현 (10-12) - 홈 헤더 "공통 자산" 버튼 → 별도 화면, `scripts/assets_lib.py`, `~/.video-cut/assets/` · 문서 지도: [`../README.md`](../README.md)

## 한 문장

**효과음·아웃트로 이미지처럼 영상마다 다시 올리지 않고 계속 재사용하는 파일을 홈의 "공통 자산" 한곳에 모은다.
등록·교체·삭제는 여기서만 하고, 각 작업 화면(인서트, 주제별 분할)은 여기 있는 것을 골라 쓰기만 한다.**

## 왜

사용자(10-12): "효과음은 환경설정보다는 공통 asset 이잖아. 따로 빼자. 여기에는 공통으로 재사용되는 효과음,
아웃트로 이미지 등이 있고 앞으로 공통 자산은 여기에 다 모으려고."

- 지금 효과음과 아웃트로는 **홈 환경설정** 창 안에 있다. 환경설정은 API 키·ffmpeg처럼 "돌리기 위한 준비"이고,
  자산은 "만들 때 쓰는 재료"라 성격이 다르다. 자산이 늘수록 설정 창이 길어지고 찾기 어려워진다.
- 종류가 늘 때마다 저장 방식·화면·서버 경로를 새로 만들고 있다(아웃트로는 `outro.png` 한 장 + `/api/brand/outro`,
  효과음은 `sfx.py` + `/api/sfx/*`). 한 틀로 모아 두면 다음 종류는 등록 한 줄로 끝난다.

## 무엇이 공통 자산인가

**기준: 사용자가 직접 올리고 바꾸는 파일, 여러 영상에서 재사용되는 것.** 코드가 들고 다니는 것은 아니다.

| | 공통 자산 (여기로) | 공통 자산 아님 (지금 자리 유지) |
|---|---|---|
| 지금 있는 것 | **효과음** (여러 개), **아웃트로 이미지** (한 장) | 글꼴(`assets/fonts`, 코드에 묶여 배포), 모션 규칙(`assets/brand/motion-rules.md`, 코드 규칙), 모션 레퍼런스(`video-references/`, 생성용 참고 자료), API 키(환경설정) |
| 앞으로 들어올 후보 | 로고·워터마크, 배경음악, 자주 쓰는 사진(강사·제품), 인서트 배경 이미지, 인트로 고정 이미지 | 영상별 결과물(인서트 이미지, 분할 인트로 후보 - 영상 폴더에 남음) |

## 화면

**홈 헤더의 "공통 자산" 버튼 → 탭을 가린 별도 화면** ("← 영상 목록"으로 돌아감, `/#assets`로 바로 열림).
처음엔 네 번째 탭으로 넣었으나(10-12) 사용자: "공통 자산은 기능과 계위가 다르다" - 탭(컷편집·인서트·주제별 분할)은
작업 종류별 영상 목록이고, 공통 자산은 그 작업들이 같이 쓰는 재료라 한 단계 위(환경설정·로그 공유와 같은 헤더)에 둔다. 환경설정에서는 효과음·아웃트로 칸을 **같은 커밋에서 뺀다**
([`../교체-절차.md`](../교체-절차.md)).

```
video-cut                     [로그 공유] [공통 자산] [환경설정]
← 영상 목록   공통 자산

효과음 · 5개                                        [＋ 추가]
  ▶  띵           0.4s   인서트 12곳   [이름] [삭제]
  ▶  휙           1.2s   인서트 3곳    [이름] [삭제]

아웃트로 이미지                                      [바꾸기]
  [ 1920x1080 미리보기 ]   주제별 분할 마지막 편에 붙음
```

- 종류마다 한 칸. 칸 모양은 두 가지뿐이다:
  - **목록형**(여러 개, 예: 효과음): 추가(여러 파일) · 듣기/보기 · 이름 바꾸기 · 삭제.
  - **한 자리형**(하나만, 예: 아웃트로): 올리기/바꾸기 · 지우기.
- **어디서 쓰고 있는지**를 보여 준다(예: "인서트 12곳"). 지울 때 "N개 영상의 인서트에서 빠집니다"로 확인을 받는다.
  지금 효과음 삭제는 쓰는 곳을 모르고 지운다.
- 파일을 창에 끌어다 놓아도 그 칸에 들어간다.
- 문구는 라벨·경고·오류만 (설명 문장 없음).

## 쓰는 곳은 그대로

| 자산 | 쓰는 화면 | 바뀌는 것 |
|---|---|---|
| 효과음 | 인서트 상세 ③ 효과음 선택 | 없음. 비었을 때 문구만 "공통 자산에서 효과음 등록" |
| 아웃트로 | 주제별 분할 내보내기 | 없음 (경로만 새 저장 위치에서 읽음) |

## 저장 구조

```
<자산 폴더>/
  assets.json          종류별 목록 { "sfx": [ {id, name, file, duration, rate, channels} ], "outro": {file} }
  sfx/<id>.wav …
  outro/outro.png
```

- 코드는 `scripts/assets_lib.py` 하나로 합친다: 종류 표(`sfx`: 목록형·오디오·변환 규칙, `outro`: 한 자리형·이미지·1920x1080 맞춤)
  + 공통 함수(`items(kind)`, `add`, `rename`, `delete`, `path`, `usage`). `sfx.py`와 `save_outro()`는 이 안으로 들어가고 없어진다.
- 서버 경로도 하나로: `/api/assets`, `/api/assets/<종류>/upload|delete|rename|file`. 옛 `/api/sfx/*`, `/api/brand/outro*`는 **같은 커밋에서 삭제**.
  검토 서버(인서트 화면)는 읽기(`/api/assets/sfx/file`)만 둔다.
- 영상 쪽 기록(`inserts.json`의 `sfx: <id>`)은 id만 들고 있어 그대로 유효하다.

### 결정할 것: 자산 폴더 위치

| | 지금: 코드 폴더 안 `brand/` | 제안: `~/.video-cut/assets/` |
|---|---|---|
| 업데이트(git pull) | 남음 (git 제외 폴더) | 남음 |
| 플러그인을 지우고 다시 설치 | **사라짐** | 남음 |
| 이미 같은 곳에 있는 것 | 없음 | 글꼴 캐시·로그·학습 기록 (`~/.video-cut/`) |

**권장: `~/.video-cut/assets/`**. 자산은 사용자가 쌓아 올린 재료라 코드 폴더와 수명이 달라야 한다.
옮길 때는 처음 실행 시 `brand/`의 내용을 복사하고 옛 폴더는 지우지 않고 남긴다([`../업데이트와-마이그레이션.md`](../업데이트와-마이그레이션.md) 방식 - 백업, 삭제 안 함).

## 단계

| 단계 | 내용 | 확인 |
|---|---|---|
| A1 | `assets_lib.py` + 새 서버 경로, `sfx.py`·`save_outro`·옛 경로 삭제, 저장 위치 이전(+ 옛 `brand/` 복사) | 기존 효과음 id가 그대로 인서트에서 재생·내보내기 됨, 기존 아웃트로가 분할 내보내기에 붙음 |
| A2 | 홈 "공통 자산" 탭, 환경설정에서 두 칸 삭제, 쓰는 곳 수 표시, 끌어다 놓기 | Playwright로 탭·추가·삭제 확인, 콘솔 오류 없음 |
| A3 | 다음 자산 종류가 생길 때 종류 표에 한 줄 추가 | — |

A1과 A2는 같이 배포한다 (옛 화면과 새 화면이 동시에 있으면 안 됨).

## 하지 않는 것

- 자산을 영상 폴더로 복사하지 않는다. 영상은 id로 가리키고, 내보낼 때만 실제 파일 경로를 FCPXML에 넣는다.
  (그래서 공통 자산에서 지우면 이미 내보낸 FCP 프로젝트의 파일도 사라진다 - 삭제 확인 문구에 넣는다.)
- 폴더 나누기·태그 같은 정리 기능은 자산이 수십 개를 넘을 때 다시 본다.
- 여러 사람이 같이 쓰는 공유(클라우드 동기화)는 범위 밖.

## 결정 기록

- 10-12: 효과음·아웃트로를 환경설정에서 빼서 "공통 자산"으로 모으기로 (사용자). 화면 위치(홈 탭)·저장 위치(`~/.video-cut/assets/`)는 권장안대로 승인("구현해").
- 10-12 구현: `assets_lib.py`(종류 표 `KINDS`, 목록형/한 자리형), 홈 서버 `/api/assets`·`/api/assets/upload|delete|rename|file`, 검토 서버는 `/api/assets/file`만. 같은 커밋에서 삭제: `scripts/sfx.py`, `save_outro()`, `common.BRAND_DIR/BRAND_OUTRO`, `/api/sfx/*`, `/api/brand/outro*`(홈·분할 서버), 환경설정의 아웃트로·효과음 칸. 이전: 처음 실행 때 `brand/`의 outro.png·효과음을 복사(옛 폴더는 남김). 쓰는 곳 수는 효과음만(영상 폴더의 `inserts.json`을 훑어 취소 안 한 인서트 수). 이름 바꾸기는 `prompt()`. 끌어다 놓기 지원. 분할 화면의 "아웃트로 없음" 링크는 `/#assets`로.
- 10-12: 네 번째 탭 → 헤더 버튼 + 별도 화면 (사용자: "공통 자산은 기능과 계위가 다른데 정리해봐"). 탭은 영상 목록만, 자산 화면에서는 "+ 새 영상"을 숨김, 마지막 작업 탭을 기억해 뒤로 갈 때 돌아감. 예전에 저장된 마지막 탭 `assets`는 컷편집으로.
