# R3. 신뢰 장치 — 오삭제 0을 사용자가 확인할 수 있게 (이음새 릴)

상태: ✅ 09-29 구현 완료 · 우선순위 1 · 배경: [`왜-이탈하는가.md`](왜-이탈하는가.md)

이음새 릴(`web/index.html`, `R` 키/`#btnReel`): `S.cut_spans` 전체를 앞뒤 1.5초씩 이어서 순차 재생, 거슬리는 곳에서 `Enter`로 그 자리에 멈춘다(카드까지 자동으로 열지는 않음 - 모든 cut_spans가 리뷰 카드로 깔끔히 대응하는 건 아님). 오삭제 신고(`#popReport`, `report_bad_cut` 결정 타입): 즉시 복원 + 해당 케이스를 평범한 살리기의 2배 가중으로 보수적으로 기록 + `~/.video-cut/reported_bad_cuts.jsonl`에 반례로 남김(정식 gold fixture 포맷은 미정). 안전 배지("신고된 오삭제 누적 N건")는 확정 모달에 표시. **회귀 게이트는 새로 안 만들고 기존 `eval_against_gold.py`로 충분하다고 판단** — 임계값·프롬프트를 바꿀 때마다 이걸 돌려 오삭제(flag 없이 조용히 잘린 것) 0건을 확인하는 게 이미 이번 세션 전체의 관행이었다(결정-이력 참고). BS145 정답지 기준 확정으로 전체 흐름 검증 완료.

- **확정 전 이음새 릴**: 모든 자동 컷 지점의 앞뒤 1.5초씩을 이어서 한 번에 재생한다 (40컷이면 약 2분). "혹시 잘못 잘린 게 있나"를 전수 확인하는 가장 빠른 방법. 가상 재생 인프라를 그대로 쓴다. 이상한 곳에서 `Enter`를 누르면 그 컷이 바로 선택된다
- **오삭제 신고**: 취소선 팝업에 "자동으로 잘못 잘렸음" 버튼. 누르면 복원 + 해당 케이스의 개인 선호를 한 단계 보수적으로 + `gold`에 반례 fixture로 기록. 사용자가 "고치면 다시는 안 틀린다"를 체감하게 하는 장치
- **안전 배지**: 결과 영수증([`R1-결과-영수증.md`](R1-결과-영수증.md))의 "신고된 오삭제 누적 0건"이 곧 신뢰 지표. 한 건이라도 생기면 숨기지 않고 보여주고, 어떻게 고쳐졌는지 링크
- **회귀 게이트**: 프롬프트·임계값을 바꿀 때마다 gold 전체를 돌려 오삭제 0을 확인. 사용자에게 보이지 않지만 이 항목의 전제 조건 — [`../기획/06-검증과-측정.md`](../기획/06-검증과-측정.md)에서 품질 루프용으로 설계 중
