# R8. 실패해도 떠나지 않게

상태: 🔄 핵심 완료(10-01) · 우선순위 2 · 배경: [`왜-이탈하는가.md`](왜-이탈하는가.md)

10-01: 서버·화면이 필요 없는 아래 두 개를 `scripts/run.py`에서 먼저 끝냈다 - 실제 실패(LLM 쪽을 일부러 실패시키는 더미 스크립트)로 양쪽 경로 모두 테스트 확인.
- **단계 실패 시 원인 안내**: `step()`이 실패를 잡아 "위 에러 메시지가 원인(API 키 만료/네트워크/ffmpeg가 흔함) - 단계별로 캐시되니 원인 해결 후 같은 명령으로 다시 실행하면 이어서 진행됨"을 출력하고 다시 던진다. 터미널에 원인+재시도 안내로 동등한 역할
- **LLM 실패 시 결정론적 자동 대체**: Stage 1/2·화자 블록(이미 `--no-llm` 결정론적 경로가 있는 세 단계)이 LLM 호출 실패로 죽으면 `step()`이 자동으로 `--no-llm`을 붙여 한 번 더 시도 + "검토 항목이 평소보다 많을 수 있음" 안내. 파이프라인이 LLM 장애로 완전히 멈추지 않음

이어서(10-01, worktree) 세 번째 항목도 끝냈다.
- **영수증에 영상당 처리 비용 추정 표시**: `scripts/common.py`의 `log_llm_usage()`가 6개 LLM 호출부(detect_regions/classify_region/detect_speaker_blocks/plan_pauses/global_review ×2/seam_refine)의 토큰 사용량을 `edit/llm_usage.jsonl`에 기록, `server.py`의 `Session.receipt()`가 합산해 `cost_est_usd`로 노출(파일 없으면 `--no-llm`처럼 LLM을 안 쓴 것으로 보고 `None`). 가격표는 `claude-api` 스킬 기준, 합성 사용량으로 단위테스트 - 실제 API 호출 비용은 안 썼음

**남은 것**: "브라우저에 재시도 버튼" 자체(지금은 터미널 안내가 동등 역할) — [R2](R2-시작-마찰-제거.md)의 "브라우저 먼저 열기"가 끝나서 구조적으로 막혀 있던 건 풀렸지만, 버튼 UI는 아직 안 올림. 급하지 않아 다음 배치로 미룸
