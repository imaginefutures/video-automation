# 시스템 개요 — 형태, 흐름, 파이프라인

상태: ✅ 동작 중
문서 지도: [`../README.md`](../README.md) · 철학·원칙: [`../서비스-개요와-철학.md`](../서비스-개요와-철학.md)

## 형태

- **Claude Code 스킬** (`~/.claude/skills/video-cut` 심링크). 자체 완결형 — video-use 등 외부 스킬에 의존하지 않는다 (video-use는 초기 참고 대상이었고 현재 코드는 쓰지 않음)
- **로컬 웹 검토 화면**: Python 표준 라이브러리 서버 + 단일 HTML. 판단은 전부 여기서 한다
- 확정 버튼이 서버에서 직접 FCPXML·미리보기를 만든다. Claude가 중간에 끼지 않는다
- Final Cut Pro는 **마무리 전용** (자막 스타일·자료 화면 배치·색). 컷 판단은 웹에서 끝난다

## 사용 절차

1. `video-edit/<이름>/raw.mp4`로 원본을 넣는다 (이름 자유, 한글 가능)
2. "video-edit/<이름> 컷편집 해줘" → 자동 처리 (BS145 24분 기준 수 분)
3. 브라우저 검토 화면에서 사이드바의 검토 항목만 처리 ([`검토-화면.md`](검토-화면.md))
4. **확정** → 폴더에 결과 생성
5. FCP에서 라이브러리 열기 → fcpxml을 브라우저 패널로 드래그

```bash
uv run python scripts/run.py video-edit/<이름>          # 전체 파이프라인 후 검토 화면
uv run python scripts/run.py video-edit/<이름> --serve  # 처리 건너뛰고 검토 화면만
uv run python scripts/run.py video-edit/<이름> --no-llm # API 비용 없이 결정론적 층만
uv run python scripts/home_server.py                # video-edit/ 전체 목록(R7) - 클릭하면 그 영상
                                                     # server.py를 새 포트에 띄워 이어서 검토
```

## 폴더와 산출물

```
video-edit/<이름>/
  raw.mp4                   원본 (사용자가 넣음)
  <이름>.fcpxml             FCP용 결과 (확정 시)
  preview.mp4               720p 미리보기 (확정 시, 백그라운드)
  edit/
    clean.mp4               tmcd·메타데이터 제거본 (FCP 호환 필수, 브라우저 재생용)
    transcript.json         단어 단위 전사 + 화자
    prosody.json            단어별 F0·에너지
    speaker_blocks.json     카메라 밖 대화 블록 + 줄별 역할
    ng_candidates.json      NG 후보 (결정론적 탐지)
    regions.json            Stage 1 "전체를 넓게" 의심 구간 (detect_regions.py, 09-30 하향식 재설계 —
                             구 context_review.json/whole_context_review.py는 폐기됨)
    ng_classified.json      Stage 2 "부분을 좁게" 분류 결과 (classify_region.py)
    ng.json                 라우팅 결과 (route: CUT/KEEP + flag: restore 복원후보/없음)
    audio_map.json          RMS 포락선 + 숨소리 구간 (로컬)
    draft_cuts.json         NG+화자블록의 모든 CUT을 합친 이음새 목록
    seams.json              이음새별 경계 선택 + 판정 결과
    final_cuts.json         이음새 루프가 확정한 최종 컷(경계 스냅 반영) — 검토 화면 배선은 아직
    pauses.json             쉼 분류 + 추천 유지 길이
    decisions.json          사람의 모든 결정 (재현 가능한 기록)
    edl.json                확정된 컷 목록
    actions.log             결정·재생·UI 이벤트 로그 (한 줄 JSON, 타임스탬프 포함)

~/.video-cut/prefs/<사용자>.json   영상을 넘어 누적되는 케이스별 선호 (검토-화면.md 개인화)
```

단계별 캐시: `edit/`에 산출물이 있으면 그 단계는 건너뛴다. 다시 하려면 해당 파일을 지운다.

## 처리 파이프라인

```
raw.mp4
 0 정리          clean_media.py          tmcd·메타데이터 제거, faststart (스트림 복사, 무손실)
 1 전사          transcribe.py           ElevenLabs Scribe, 단어 단위, 화자 분리
 2 음향          prosody.py              librosa, 로컬 연산 (API 비용 0)
 2 음향 지도     audio_map.py            RMS 포락선 + 숨소리 구간, 로컬 연산 (API 비용 0)
 3 화자 이탈     detect_speaker_blocks.py 대화 형태 구간 → 블록 + 줄별 역할      ※ 4보다 먼저
 4 NG            detect_pronunciation_candidates.py (발음 실수, 별도 채널)
                 → detect_regions.py (Stage 1, 전체를 넓게 - 의심 구간을 대략적으로 표시)
                 → classify_region.py (Stage 2, 부분을 좁게 - 정확한 경계·case 확정)
                 → route_candidates.py (최대 삭제: CUT/KEEP + 복원후보 flag, Stage 1 출신은
                   신뢰도 무관 항상 flag)
                 → assemble_draft.py (NG+화자블록의 모든 CUT을 이음새로 합침)
                 → seam_refine.py (대안 탐색 + 만든 모델과 다른 모델이 문법·중복·지시어·정보손실
                   판정, `self_critique.py` 대체 — 대안 선택 자체는 검토 화면에 아직 안 배선됨,
                   경계 스냅은 09-29일에 아래 7단계로 직접 배선함)
 5 무음          plan_pauses.py          쉼 문맥 분류 → 추천 유지 길이
 6 검토 화면     server.py + web/index.html
 7 확정          server.py의 cut_spans()가 NG/화자블록 컷마다 audio_map.choose_boundary로 경계를
                 조용한 지점에 스냅(실패 시 15ms 패딩 폴백) → export_fcpxml → 확정 직전 자기검토
                 (seam_refine.g2_check: 최종 경계마다 실제 이어붙인 오디오를 재전사해 잔여음/절단
                 의심을 확정 화면에 표시, 확정은 막지 않음) → render_preview (서버가 직접 실행)
```

화자 블록을 NG보다 먼저 돌리는 이유: 전체 맥락 검토가 이미 블록으로 잡힌 구간을 건너뛰어야 같은 구간이 두 번 보고되지 않는다. `audio_map`은 2단계 어디서든 돌 수 있지만(다른 산출물에 의존하지 않음) 병렬로 봤을 때 이해하기 쉽게 음향(prosody) 옆에 둔다.

## 기술 선택

| 영역 | 선택 | 이유 |
|---|---|---|
| ASR | ElevenLabs Scribe | 한국어 WER 3.1%, 추임새·말더듬을 원문대로 유지. mlx-whisper는 말더듬을 한 단어로 합쳐 NG 정밀도가 떨어짐. 무료 대안이 필요하면 freecut 포크 |
| 배치 LLM (영상당 30회 이상) | Anthropic API 직접 호출 | CLI 경유는 호출당 5초 이상이라 영상 1편 처리가 수십 분으로 늘어남 |
| 검토 화면 LLM (드문 호출) | `claude -p` (Claude Code 구독) | 패턴 제안·의미 검색은 세션당 몇 번뿐이라 지연 감내 가능. 별도 API 과금 없음 |
| 마무리 도구 | Final Cut Pro 12.3, FCPXML 1.11 | FCPXML이 네이티브 포맷. 마커·캡션·connected clip·Roles 지원 |
| 키 | 프로젝트 루트 `.env` | `ELEVENLABS_API_KEY`, `ANTHROPIC_API_KEY` (git 제외) |

## 모델 배정 (비용 대비 효율)

| 작업 | 모델 | 근거 |
|---|---|---|
| 쉼 문맥 분류 | Haiku 4.5 | 담화 표지로 대부분 판별. 틀려도 지워지는 건 침묵뿐 |
| NG 분류 기본 | Sonnet 5 | 후보 대부분(C/D/명백한 A)은 이 수준으로 충분 |
| NG 분류 에스컬레이션 | Opus 5 | B 케이스이거나 신뢰도 0.80 미만일 때만 재판정 |
| 화자 블록 줄별 역할 | Sonnet 5 | "어느 시도가 최종본인가"는 NG A/B급 판단 |
| 전체 맥락 검토 | Opus 5 | 영상당 1회, 품질 우선 (편당 $0.1 이하) |
| 이음새 판정 (`seam_refine.py`) | 컷을 만든 모델과 반대 (Sonnet↔Opus) | 만드는 모델과 평가하는 모델을 다르게 함 — [`../기획/02-품질-루프.md`](../기획/02-품질-루프.md) 4장 |
| 패턴 제안, 의미 검색 | Sonnet 5 | "명백히 어색한가" 수준의 판단 |

구조화 출력을 쓰는 호출은 전부 `thinking` 비활성화 (Sonnet 5 기본 thinking이 `max_tokens`를 소진하던 버그의 해결책, 비용도 절감).

모델 ID 최신화는 [`../미결-사항.md`](../미결-사항.md). 품질 루프 재설계의 모델 배정(교차 판정 포함)은 [`../기획/02-품질-루프.md`](../기획/02-품질-루프.md) 4장.
