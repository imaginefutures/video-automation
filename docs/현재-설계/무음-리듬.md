# 무음 리듬

상태: ✅ 동작 중. 숨소리 인식·에너지 최저점 기준 경계 반영 완료(10-08) — [`../결정-이력.md`](../결정-이력.md) 10-08 항목

단어 사이 쉼 중 0.12초 이상(그 밑은 Scribe 타임스탬프 오차 범위)을 대상으로, 0.35초 이상은 LLM이 문맥을 분류하고 나머지는 일반으로 본다. 단어 경계 20ms 안쪽은 절대 자르지 않는다.

| 문맥 | 남길 길이 |
|---|---|
| 일반 문장 사이 | 0.25초 (0.20–0.30) |
| 나열 | 0.11초 (0.08–0.15) |
| 인용 → 설명 전환 | 0.40초 (0.35–0.45) |
| 주제 전환 | 그대로 둠 |
| 질문 → 답 | 그대로 둠 |
| 화자 전환 | 그대로 둠 (화자 블록 층이 담당) |

목표치는 검토 화면 사이드바에서 전역 조정하고, 개별 쉼은 게이지로 조정한다 ([`검토-화면.md`](검토-화면.md) 조작).
