# 촬영 가이드 — 자동 편집을 돕는 습관

이 가이드는 선택 사항이다. 지키지 않은 영상도 편집 파이프라인은 동작한다.
지키면 자동으로 확정되는 컷이 늘고, 사람이 검토할 항목이 줄어든다.

## 1. 재시작 신호 (효과가 가장 큼)

말이 틀렸거나 더 잘 말하고 싶어서 다시 시작할 때:

1. 말을 멈춘다
2. **"다시"** 라고 짧게 말한다
3. **2초** 쉰다
4. 다시 시작할 문장의 처음부터 말한다

이 네 단계가 지켜지면 "다시" 앞의 실패 시도는 확인 없이 자동 삭제 대상이 된다.
"다시" 대신 손뼉 한 번도 가능하다. 둘 중 하나로 통일하는 것이 좋다.

주의할 것:
- "다시" 뒤에 바로 이어 말하지 않는다. 2초 쉼이 있어야 신호로 인식된다
- 문장 중간부터 이어 말하지 않는다. 문장 처음으로 돌아간다
- 강의 내용 안에서 "다시"라는 단어를 쓰는 것은 상관없다. 쉼이 없으면 신호로 보지 않는다

## 2. 재시작 없이 계속 말하는 경우

아래는 재시작이 아니므로 신호 없이 그냥 말하면 된다. 자동 편집이 살린다.
- 강조를 위한 반복 ("정말 정말 중요합니다")
- 같은 내용을 다른 말로 다시 설명 ("다시 말하면", "즉")
- 나열 ("첫째, 둘째, 셋째")

조사나 어미만 고쳐 말하는 것("하나의… 하나를")은 신호 없이 그냥 고쳐 말하면 된다. 틀린 단어 뒤에 아주 짧게라도 쉬고 고친 단어를 또렷이 말하면 자동으로 잘려 나간다. 쉼 없이 붙여 말하면 검토 항목으로 올라간다.

앞 문장을 버리고 같은 내용을 더 잘 말하려는 것이면 1번 신호를 쓴다.
신호가 없어도 내용 비교로 판별하지만 검토 항목으로 올라갈 확률이 높다.

## 3. 영상 시작과 끝

- 녹화 시작 후 **3초** 침묵하고 시작한다
- 마지막 문장 후 **3초** 침묵하고 녹화를 끝낸다

앞뒤 여유가 있어야 첫 단어와 마지막 단어의 경계를 정확히 잡을 수 있다.
이 3초는 신호가 아니라 여유 공간이다. 영상 중간에 3초 넘게 쉬어도 상관없다 — 첫 단어 앞과 마지막 단어 뒤는 위치로 정해지고, 중간의 쉼은 4번 규칙으로 따로 처리된다.

## 4. 쉼(pause)

문장 사이 쉼은 자동으로 정리되니 의식하지 않아도 된다.
다만 아래는 의도적인 쉼으로 판단해 손대지 않으므로, 리듬을 살리고 싶은 곳에서는 충분히 쉬어도 된다.
- 주제가 바뀔 때
- 질문을 던지고 답을 말하기 전

## 5. 소리

- 마이크 위치와 입력 레벨을 촬영 내내 고정한다 (음량은 편집에서 -14 LUFS로 맞추지만 중간에 바뀌면 컷 경계에서 튄다)
- 재시작할 때 종이를 넘기거나 물건을 만지지 않는다. 그 소리가 말과 겹치면 경계 판단이 어려워진다
- 배경음악은 촬영 때 틀지 않는다. 편집에서 넣는다

## 6. 화면

- 재시작 전에 카메라에서 시선을 떼거나 자세를 고쳐도 된다. 오히려 재시작 신호로 쓰인다
- 프레이밍(카메라 위치, 줌)은 한 영상 안에서 바꾸지 않는다. 컷 경계에서 화면이 튄다
- 자료 화면이 들어갈 자리에서 "여기 그래프가 나옵니다"처럼 말로 표시해 두면 자료 삽입 위치를 잡기 쉽다

## 7. 파일

- 한 강의를 여러 파일로 나눠 찍어도 된다. 파일명에 순서를 넣는다 (`01_intro.mp4`, `02_main.mp4`)
- 다시 찍은 파일은 앞 파일을 지우지 말고 그대로 둔다. 마지막 파일을 최종으로 본다

## 요약 카드 (촬영 전 한 번 보기)

```
시작 3초 침묵
틀리면 → "다시" → 2초 쉼 → 문장 처음부터
강조·나열·재설명은 그냥 말한다
마이크·프레이밍 고정
끝 3초 침묵
```
